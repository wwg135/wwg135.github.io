### 🔒 锁屏 & 系统美化

| 插件 | 功能简介 |
| :--- | :--- |
| **SwipeUnLock** | 自定义锁屏“向上轻扫以解锁”“没有更多通知”等文字 |
| **自动面容ID解锁** | 面容识别后直接进入主屏，隐藏解锁图标，延迟最小 |

| **双指下滑截图** | 双指从屏幕顶部下滑即截图，无设置项 |
| **隐藏“没有更早的通知”** | 锁屏隐藏该文字提示 |
| **隐藏相机手电筒** | 隐藏锁屏相机/手电筒按钮，禁用左滑 |
| **隐藏手势小横条** | 隐藏底部 Home 小横条与返回小白条 |

| **通知分组堆叠** | 通知不堆叠，可连续逐条显示 |
| **隐藏通知背景** | 任何位置的通知背景全透明 |
| **背景透明** | 通知中心、控制中心、小组件、文件夹、切换器透明 |
| **状态栏优化** | 隐藏热点、闹钟、蓝牙、VPN、旋转、勿扰等图标 |
| **多任务后台** | 后台透明、iPad 卡片式、隐藏图标标签 |
| **主屏幕优化** | 隐藏截图预览、蓝点黄点、小白点，禁用搜索与负一屏 |
| **隐藏主屏幕黄点** | 隐藏 App 左上角蓝点 / 黄点 |
| **隐藏设置商店应用** | 隐藏设置里的第三方 App 列表，支持 iOS 15+ |
| **隐藏 Dock 背景** | Dock 背景透明 |
| **DockHeight** | 自由调整 Dock 高度，建议搭配 Dock 透明 |
| **VisionOS** | VisionOS 风格主题 |

- 适用于 **Dopamine、Relaxin（Roothide）** 等 iOS 15+ 无根 / 隐根越狱环境
- 推荐使用 **Sileo** 或 **Irisin** 包管理器
